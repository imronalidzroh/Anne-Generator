## 2025-05-15 - [Accessibility & Feedback Micro-UX]
**Learning:** Adding `for` attributes to labels and `aria-live` regions to toasts significantly improves screen reader accessibility with minimal code changes. Implementing a simple loading state on async buttons prevents double-submissions and provides immediate visual feedback, which is crucial for a smooth user experience.
**Action:** Always check for missing `for` attributes on labels and ensure asynchronous actions have visible loading states and accessible notifications.
